# AX-04B 实时帧与参考接口

实时候选在 `ax04b_realtime_0` 使用 4 KiB AXI4-Lite 映射，构建目标地址为 `0x80002000`。R5 软件使用本次 XSA/BSP 给出的地址和 PL 到 GIC 的中断编号。IRQ 为高电平有效，保持到精确序号 ACK。ADC、早期帧快照、参考采用和该 AXI 从设备共用 PS `pl_clk0`，名义 50 MHz。PWM 采用保持现有 2∶1 相关时钟桥。原 `0x80000000` 观察器快照与标定、`0x80001000` PWM 状态仍有各自用途。 [实时 AXI RTL](../../hardware/axu5ev/motor_control/rtl/axi/ax04b_realtime_axi.sv) · [布线源](../../hardware/axu5ev/motor_control/bd/adc.tcl)

## 实时窗口

`sample_id` 是 ADC 转换序号，每个选中帧加 500。`tick` 是 P0 时的完整 `uint64` 时标，每个选中帧加 5000。两者均按各自位宽回绕。参考传输版本是另一个 `uint32`，与模型参考版本及 IRQ 序号分别记录。

| 50 MHz 相位 | 合同和停止判据 |
|---|---|
| P0[k] | 锁存当前样本的编码器元数据和时标，按目标 `sample_id[k]` 采用上一轮已接受参考。目标不匹配、缺包、撤销时丢弃并禁止旧参考。 |
| P4 / P74 / P75 | 现有 ADC 接收器收集身份与元数据，七转换拍后给出选中原码对。新生成电流边界在其后一个逻辑拍寄存电流资格、标定版本和结果事件。 |
| P76 | AXI 从设备冻结同帧最小反馈并置 IRQ。资格为假也进入该路径。角度和 PWM 状态独立完成。 |
| P110 附近 | 独立生成的角度与电流完成会合，供 PL 自己推进此帧的 FOC。 |
| P127 / P128 | 冻结同帧的九个 FOC 输入，下一拍开始生成核的完整 5000 拍使能周期。 |
| P443 附近 | 定点 FOC 输出，再经生成比较值映射器递交三相整组。 |
| P2500 | PWM 谷值采用当前选中样本身份的合法三相结果。接受、采用和回传为分别可观测的事件，完整 80 字诊断快照在谷值后发布。 |
| 最晚 P4984 | RTL 允许在这里完成 `COMMIT` 判定并冻结下一 P0 包，留 16 个逻辑时钟边界余量。同一 P0 边沿到达的提交拒绝。 |
| P0[k+1] | 只采用目标身份 `sample_id[k]+500` 的整包，记录实际采用版本和目标。 |

名义从 P76 到 P4984 有 4908 个逻辑拍，约 98.16 µs。板内需测量 `IRQ 响应 + 快照读 + 生成函数 + 格式转换/写入 + PL 接受`，计入非实时快照的有界屏蔽窗口，并按实际 IRQ/COMMIT/P0 事件比对。最终判据为 `IRQ 到可见接受` 小于反馈到下一 P0 的可用时间减 16 拍余量。PMU 软件段耗时和 PL 相位分别保留，绝对中断延迟以两端关联迹线确认。PR24 旧回放最大 86.017 µs 是历史线索。ARM 中断响应/执行和新的实测窗口本轮 `NOT_RUN`，通过编译或仿真也不作 WCET 证明。 [旧回放时间](../../coordination/reports/ax02c2_runtime_pl_replay.md) · [早期帧源](../../hardware/axu5ev/motor_control/rtl/top/ax03b3_adc_observer.sv)

## 读接口和 IRQ

偏移按字节，32 位小端，低字在前。快照银行的本轮读事务可任意顺序重复，中间无需 BEGIN。一次 IRQ 先检查 `STATUS.pending`，读序号和完整字段，处理及提交后用同一序号 ACK。没有 pending 的快照字返回 0，不能据此推断存在第 0 帧。

| 偏移 | 字段 |
|---|---|
| `0x00` / `0x04` / `0x08` | 接口身份 `0x41584201` / 构建 `1=SELFTEST`, `2=REAL` / `1000 nm/count` |
| `0x0c` | `[0]` pending，`[1]` 锁存禁止，`[2]` armed，`[3]` 已排队参考，`[4]` 已采用参考仍有效，`[5]` overrun 粘滞，`[6]` 曾见选中帧，`[7]` 正处同步快速故障或撤销，`[8]` 曾接受参考，`[9]` 曾采用参考 |
| `0x10` / `0x14` | 当前读取银行事件序号 / overrun 总计数 |
| `0x18` / `0x1c` | 最近实际接受参考版本 / 目标样本号 |
| `0x20` / `0x24` | 最近实际采用参考版本 / 目标样本号 |
| `0x28` / `0x2c` | 本次提交结果 / 最近 P0 样本号 |
| `0x30` / `0x34` / `0x38` | 选中样本号 / `tick[31:0]` / `tick[63:32]` |
| `0x3c` / `0x40` | 同帧 ABZ 原始计数 / 非法跳变累计 |
| `0x44` | `[0]` 编码器就绪，`[1]` 电流有效，`[2:3]` A/B 已标定，`[4]` 饱和，`[5]` TEST 标记，`[6:7]` A/B 捕获有效，`[8]` 双通道齐备，`[9]` 编码器方向 |
| `0x48` / `0x4c` / `0x50` | 标定版本 / ADC 配置版本 / 同帧故障字 `[0]` ERRI、`[1]` ERRU，1 为有效故障 |
| `0x54` | 当前 P0 相位，0…5000 饱和，独立于冻结银行 |

旧 ACK 与错误序号都是无动作。精确 ACK 和新事件同拍时，旧银行释放，新银行立即锁存，pending 保持。未及时 ACK 就有新事件时，旧银行不变，新事件计入 overrun 且触发禁止。事件序号按选中事件前进，包括被记录为丢失的事件。整包完全相同的重复帧不重发 IRQ。同身份的计数、资格或故障有变化时仍允许进入安全调度。无反馈时不等待无限重试。 [端口与传输验证](../../verification/experiment/ax04b/ax04b_realtime_axi_tb.sv)

## 写接口、格式和执行状态

| 偏移 | 字段 |
|---|---|
| `0x80` | ACK 精确事件序号 |
| `0x84` | `1=STOP`、`2=CLEAR`、`4=ARM`。写入独立命令值。 |
| `0x88` / `0x8c` | 目标 `sample_id+500` / `COMMIT` 密钥 `0x434f4d4d` |
| `0x90` | R/W bit 0 请求 `CTRL_EN` 输入缓冲使能，复位与 STOP 清零。SELFTEST 的外部缓冲门控保持低。 |
| `0xa0` / `0xa4` | Id/Iq，带符号 A/Q24。原始整数范围分别为 ±8388608 和 ±5033165。 |
| `0xa8` / `0xac` | 电角速度 rad/s/Q24 的低/高字，带符号 40 位扩展到 64 位 |
| `0xb0` / `0xb4` | 电角偏置 rad/Q32 的低/高字。软件归一化后，RTL 接受 `[0,26986075409)`。 |
| `0xb8` | `[0]` 固定角选择，`[1]` PWM 请求，`[2]` PI_Reset，`[3]` 参考合法，`[4:5]` RELCON/ENCON，`[6]` F_Reset，`[7]` OE_Disable |
| `0xbc` | 传输版本。相对上一已接受版本须为模 `2^32` 正向半区差值。 |

参考模板由目标字与 8 个参考字组成，每次 `COMMIT` 尝试消耗这一轮的写入掩码。全字写齐、有效密钥和字段、当前免过期、锁存反馈源的本帧身份、下一个精确目标、单槽空闲和新传输版本都成立才接受，shadow 也可在之后重写而不影响队列。`0x28` 返回 `0=未尝试`、`1=已接受`、`2=迟交或错误目标`、`3=忙`、`4=包不完整或格式非法`、`5=旧/重复版本`、`6=安全拒绝`。AXI 的 `BRESP` 说明总线写入状态，`accepted_version/target` 和 `applied_version/target` 分别说明 PL 排队和 P0 采用。

格式校验覆盖电角速度的有符号扩展、偏置区间、电流限制、保留位和许可一致性。PWM/REL/EN 请求要求本帧完整资格与引脚条件成立，且和 F_Reset 互斥。无 PWM/REL/EN 请求的安全包仍可更新诊断和运行态。F_Reset 可通过采用的安全包单独请求，外部控制缓冲的可用性仍由硬件定义。STOP、配置撤销、overrun、非法参考提交和 armed 后缺包的 P0 均撤销在途状态。快速故障立即通过独立禁止链，去除故障后还需显式 `CLEAR` 和 `ARM`，增加版本本身不解除禁止。P0 停止或 R5 停提交后，最后一次接受起 10000 个逻辑拍的看门狗使参考失效。应用 FPGA 引脚层还按候选配置硬禁止门极及驱动使能。 [PWM 集成](../../hardware/axu5ev/motor_control/bd/pwm_clock.tcl)

## 定向复现

```powershell
.\scripts\motor_control_run_rtl.ps1 -Suite ax04b-axi
.\scripts\motor_control_run_rtl.ps1 -Suite ax04b-chain -Ax04bMode SELFTEST
.\scripts\motor_control_run_rtl.ps1 -Suite ax04b-chain -Ax04bMode REAL
```

AXI 测试使用缩短的周期参数以覆盖总线背压、有效与无效 IRQ、重复状态变化、半写、忙、过期、序号及采样回绕、同拍 ACK、overrun、故障撤销、F_Reset 分离及看门狗。联接测试使用 5000 拍的实际帧长度、实机源表、真实 RTL 观察器和 PWM 桥。R5 侧由测试平台作 AXI 主机。 [测试入口](../../scripts/motor_control_run_rtl.ps1) · [联接测试平台](../../verification/experiment/ax04b/ax04b_chain_tb.sv)
