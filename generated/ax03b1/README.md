# AX-03B1 generated current preprocessing

`AXU5EV_RealIO_NoPower/Current_Preprocess.sv` and `Numeric_Algorithm.sv`
are generated by HDL Coder from the independent observer model's
`Current_Preprocess` subsystem. Do not edit these files to fix arithmetic.
Change the new model's numeric source/body through MATLAB MCP, then regenerate.

MATLAB MCP entry: add `simulation/real_io` to the path and call
`ax03b1_run_no_power(true)`. It runs only the new model/numeric checks and
regenerates this subsystem. Tool-created reports/cache/auxiliary models remain
local; only the two necessary SystemVerilog design sources are tracked.

The adapter holds `clk_enable=1`; all 14 outputs, including result_strobe,
quality/error and calibration version, have one registered clock of latency.
No FOC, Runtime, speed estimator, physical capture circuit or power permission
is generated here. Behavioral verification is distinct from synthesis, STA,
physical CDC/analog validation and board measurements (all NOT_RUN).
