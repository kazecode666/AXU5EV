# AX-00B — ALINX AXU5EV 厂商资料核查、精选整理与工程接口清单

> 任务定位：AX-00迁移后的板卡资料盘点，为AX-01 R5F软件边界和AX-02 PL接口设计提供事实依据。**本任务不开展固件、RTL和实际硬件操作。**

## 输入及限制

目前远端仅有用户提供的厂商`readme_资料目录.txt`目录结构，本地Codex可以读取用户已放入本机的**实际资料包**。目录列表只说明资料类别，尚不足以确定实际项目文件、版本或授权条件。先读取 [目录优先级与核查规则](../../docs/AXU5EV_VENDOR_MATERIALS_ZH.md) 和 `coordination/HANDOFF.md`。

- 研究分工不变：R5F运行位置/速度/原对齐与参考管理；PL执行电流FOC、采样/位置输入锁存、PWM及快速禁止。
- 本地用户原厂资料**只读**，先核实真正所在目录，再逐项枚举；不将预想目录当事实，不解压/修改原厂包，不复制整个厂商资料树到Git。
- 厂商PDF/ZIP/RAR、镜像、第三方手册等默认 `INDEX_ONLY` 或忽略的 `LOCAL_ONLY`。确认允许再分发才精选入库；禁止因为仓库私有就默认版权允许。
- 用户本地目录、已迁SLX/RTL、未提交修改和未保存窗口必须保护。不要未经确认合并AX-00 PR，也不要改旧项目、强推或自动上电/烧录。
- 厂商目录说明使用 Vivado 2020.1；当前R2026b与Vivado/xsim2026.1的兼容需要实测，不改变厂家工程来伪装新版。
- 使用既有 `kazecode666/AXU5EV` 仓库。在AX-00的PR1合并后以最新main建立实现分支，不能修改已经通过Review的迁移分支；最终提交新的开放PR供ChatGPT Review。

## A. 实物型号与文件盘点

1. 列出资料根目录中实际一级/二级文件及ZIP/RAR清单（只枚举，不执行未受信任脚本）。计算名称、字节数、SHA-256、扩展名和可见厂商版本，引用相对路径，避免提交本地私人绝对路径。
2. 先审 `xx用户手册.pdf`、`00_hardware.rar` 和核心/底板丝印或已有实物说明，**确认确切AXU5EV型号后缀、底板修订、ZU5EV完整料号**。遇到AXU5EV-E/B-E/P不一致，记录冲突并禁止继续猜板级引脚和时钟。
3. 查看已有 `hardware/axu5ev/BOARD_INVENTORY.md` 和 `references/INDEX.csv`，标出新增事实与原本未确认项。若缺实际料号，保持 `UNCONFIRMED`。

## B. 重点压缩包内容核查（不运行任何例程）

| 来源 | 核查重点 |
|---|---|
| `00_hardware.rar` | 核心板+底板原理图、结构、管脚分配、IO Bank电压、电源/时钟/复位、JTAG/启动、板间连接器及收发器 |
| `course_s2.zip` + s2 PDF | Vitis中具体processor/domain选项是R5F还是A53、standalone BSP、GIC/定时器、UART、AXI-Lite、PS—PL交互、中断/DMA演示 |
| `course_s1_fpga.zip` + s1 PDF | PL接口/时钟约束、PS到PL桥接、AXI GPIO/BRAM/中断、IO电平及可复用时序/仿真工程 |
| `factory_vivado.zip` | PS配置、clock/reset、MIO/EMIO、板卡端口、XSA/BD和旧版IP依赖；不要直接改老工程或把它重标为2026.1 |
| `配套模块` | 仅查看真实存在的电流ADC、位置尺协议、RS422/LVDS、通讯或隔离资料；匹配当前系统接口，不能依据类别猜有货 |
| s0、s6、lwIP、eMMC | 按需查看并记录优先级；不影响AX-01启动 |
| Linux/AI/VCU及出厂镜像 | 只留类别/版本索引，当前不搬大文件 |

必要时在忽略的 `.runtime/vendor_review/` 下**限量解包**单独检查；记录实际被阅读的文件。安全检查异常路径、文件大小、脚本和二进制，不执行陌生安装器或预编译脚本。

## C. 电机控制接口交付

从实际手册/原理图取得可追溯的表格（每行对应文档/页码或工程文件）：
- PS/R5F时钟、内存、split/lockstep、启动流程、UART/JTAG及AXI/中断的可核查入口；**裸机S2例程若只面向A53，明确标记不可直接移用**。
- PL可用时钟、引脚与Bank电压、扩展头或FMC接口、电平与差分要求、隔离和驱动快速禁止脚。
- 外部电流ADC及光栅/磁栅实际接口资料可否复用、需要什么收发器和实时采样信号；没有电路/芯片型号就标 `MISSING`，不创建猜测XDC。
- 原有采样/PWM合同：100us电流、1ms速度、10ms位置、50us应用边界（当前参考），明确未来加入ADC、位置接口与PS—PL交换后仍需重新量测的时延。
- `course_s2`、`factory_vivado`涉及的旧版IP/Vitis domain迁移风险列表。

提交 `hardware/axu5ev/ALINX_BOARD_FACTS.md`（已证实事实）、`references/alinx/ALINX_MATERIALS_INVENTORY.csv`（原始资料索引）、`coordination/reports/ax00b_vendor_review.md`（可复现核查记录）。同步更新已有 `BOARD_INVENTORY.md`、`references/INDEX.csv`，不能相同信息出现矛盾。尚未读取的资料全部标 `NOT_INSPECTED`。
