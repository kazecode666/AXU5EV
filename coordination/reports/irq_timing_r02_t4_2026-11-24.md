## 一帧内测什么，下一帧验什么

| 时点 | 操作与判据 |
| --- | --- |
| P0 → P76 | PL 名义 50 MHz，每拍 20 ns，每帧 5,000 拍即 100 µs。P76 冻结最小反馈及身份并置电平 IRQ。完整诊断快照另行读取。 |
| R5 进入 IRQ → 读反馈 → 计算 | 首次 PHASE 的读边沿给出 P76 至 C 入口的保守上界，含 GIC、向量和入口后读寄存器开销。用 BSP 的 499,994,995 Hz 与导出 PMU ÷64 换算软件阶段，每计数约 0.128 µs，短段用 uint32 模差，长窗用 PL uint64 tick。 |
| 模型 → 写入 → 接受回读 | 依生成代码的计数与触发状态区分普通、1 ms 速度、10 ms 位置与速度共同到期帧。模型段含准备，提交段含编码/AXI 写入、DSB 和 RESULT/version/target 回读。ILA 未引出 accept_commit。用写前、读回后的 PHASE（寄存值 + 1）和两侧 P0_ID 锚定同一 sample_id。对已接受且身份/相位合法的参考，取写前读边沿作下界，写后读边沿与 P4984 较小者作上界。 |
| 截止与 ACK | P4984 仍按边沿前 p0_age=4983 判定接受。P76→P4984 有 4,908 拍即 98.16 µs，下一 P0 前预留 16 拍。余量按同帧接受上界从截止扣除。精确 seq ACK 后记录 ISR 尾采点；函数返回、最终极值更新、GIC EOI 与 BSP 退栈仍在采点之后。用后续 seq、ACK、overrun 检查下一 IRQ。 |
| 下一 P0 与 P2500 | 提交目标为 sample_id+500（uint32 模差）。下一 IRQ 在自身提交前读取上一包 applied version/target，核对 seq 加 1、tick 加 5,000、目标样本及身份。自然到期的末个有效帧仍需后续回执。P2500 的内部 FOC/PWM 谷值采用另用冻结快照、offer、采用序号及独立 PWM 回读核对。 |

PL IRQ 121、GEM3 IRQ 95 共用 GIC，优先级分别为 0x90、0xA0，普通 IRQ 向量执行期间屏蔽 IRQ。GEM ISR 屏蔽自身并置标志，前台执行 DMA、lwIP/TCP 和 JSON。前台屏蔽观测覆盖应用 irq_lock 和包装的 BSP cache flush/invalidate，包含包装开销，采点外的 CPSR/返回未计。测量候选额外做 AXI 读和固定内存统计，IRQ 内无打印、分配或网络收发。Summary 累计全窗各 rate 的 count/min/sum/max 及峰值身份，异常与转换另存。Detail 与业务 Trace 共用 256 条 RAM，10 kHz 下只能连续记录 25.6 ms，每次拷贝也会消耗时间。[测量实现与边界](../../firmware/r5/motor_control/IRQ_TIMING_ZH.md)
